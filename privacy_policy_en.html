2. Data We Collect

2.1 Account Data

When you create an account, we process:

  • Email address – for identification and optional communication
  • Firebase User ID (UID) – to associate your data
  • With Google Sign-In: name and profile picture (provided by Google)

Stored by Google Firebase Authentication (EU/US data centers).

2.2 App Content Data

For registered users, the following is stored on our backend server (gustoapp.onrender.com, hosted at Render.com, USA):

  • Meal plan and scheduled recipes
  • Pantry inventory
  • Dietary preferences and recipe ratings
  • Custom recipes
  • Subscription/premium status
  • Referral code and invitation count

Legal basis: Art. 6(1)(b) GDPR (contract performance).

2.3 Recipe Images

Images in custom submitted recipes are stored at Cloudinary (USA).

2.4 In-App Purchases

Purchases via Google Play. Gusto only receives confirmation of active subscription status – no payment data.

2.5 Play Integrity API

To prevent fraud, the app checks installation authenticity via Google Play Integrity API. An integrity token is transmitted to our server.

2.6 Local Data (Without Account)

Without an account, data is stored only locally on your device (SharedPreferences) and never leaves it.

4. App Permissions

  • Internet: Required – for recipe data, sync, and backend communication
  • Camera (optional): Only for taking photos for custom recipes or support requests
  • Notifications (optional): For meal-time reminders
  • Billing: For in-app purchases via Google Play

5. Your Rights (GDPR Art. 15–22)

  • Access: You can request information about what data we hold about you.
  • Rectification: Incorrect data can be corrected on request.
  • Erasure: Delete your account anytime via Account → Delete Account. All server data will be removed.
  • Portability: We can provide your data in a common format on request.
  • Objection: You can object to processing, which will result in account deletion.
  • Complaint: You have the right to lodge a complaint with a supervisory authority.

6. Data Security

  • All connections are TLS/HTTPS-encrypted
  • API access is secured with API keys
  • Firebase Authentication uses secure token-based auth
  • Passwords are hashed by Firebase – the Operator has no access

7. Retention

Data is retained as long as your account is active. After account deletion, all server data is permanently removed within 30 days. Firebase authentication data is deleted immediately.

8. Children

The app is not intended for children under 16. We do not knowingly collect data from minors.

9. Changes

Material changes to this policy will be communicated in-app. The current version is always available at this URL.
